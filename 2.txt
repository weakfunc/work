## 1. 工程概述

本工程是一款面向**纯电动/增程式电动汽车主驱电机控制器（EDU - Electric Drive Unit）** 的嵌入式软件工程，基于 **AUTOSAR 架构**开发，目标处理器为英飞凌 **TC377（TriCore 架构）** 三核 MCU。

### 核心功能

| 功能域 | 描述 |
|--------|------|
| 整车控制（VCU） | 驱动力矩仲裁、模式管理、高低压管理、充电管理、增程器控制 |
| 电机控制（FOC） | 磁场定向控制、电流环、弱磁控制、位置观测、PWM调制 |
| 功能安全（FuSa） | ASIL-D级安全监控、SMU告警处理、硬件关断路径测试 |
| 诊断（Diag） | UDS诊断服务（22/31等）、OBD、防盗（IMMO）、JTAG锁定 |
| 通信（Com） | CAN/LIN通信管理、E2E保护、网络管理 |
| 故障管理（Flt） | DTC故障码管理、MIL灯控制、故障使能条件 |
| 数据存储 | NVM/FEE数据持久化（标定数据、故障记录、里程等） |

## 3. 软件架构

本工程遵循 **AUTOSAR Classic Platform** 分层架构：

```
┌────────────────────────────────────────────────────────────────┐
│                     应用软件层（ASW）                           │
│  VCU_xxx | FOC_xxx | FUSI_xxx | AppCom | AppDiag | AppFlt     │

│                  运行时环境（RTE）                              │
│              VCU_Rte.h / Rte_Fusi_SWC.h                       │
├────────────────────────────────────────────────────────────────┤
│             服务层（Services）/ BSW模块                         │
│    OS | EcuM | BswM | Com | Dcm | Dem | Fee | Smu | Mcu ...   │
├────────────────────────────────────────────────────────────────┤
│             复杂设备驱动（CDD）                                  │
│  CDD_GD3162 | CDD_TLF35584 | CDD_DSADC | CDD_GTM | MCS ...   │
├────────────────────────────────────────────────────────────────┤
│              MCAL（微控制器抽象层）                              │
│      Adc | Spi | Gpt | Pwm | Dio | Port | Dma | Irq ...       │
├────────────────────────────────────────────────────────────────┤
│                  硬件（TC377）                                   │
│        GTM | DSADC | QSPI | CAN | LIN | GPIO | MTTU ...       │
└────────────────────────────────────────────────────────────────┘
```

### 3.1 AUTOSAR关键概念

- **SWC（Software Component）**：应用层软件组件，通过 RTE 接口相互通信
- **RTE（Runtime Environment）**：软件组件间的虚拟总线，屏蔽底层细节
- **IOC（Inter-OS-Application Communicator）**：跨 OS Application（即跨核）通信机制
- **CDD（Complex Device Driver）**：不完全遵循 AUTOSAR 分层的特殊驱动（直接访问硬件）
- **OS Application**：AUTOSAR OS 中的隔离单元，每个核有独立 OS Application
- **EcuM**：ECU 状态管理模块，负责 ECU 启动/运行/关机的状态机

### 5.2 核间启动同步机制

工程使用全局变量实现核间同步屏障：

| 变量名 | 含义 |
|--------|------|
| `glOSCore0BarrierInitPhase` | Core0完成基础安全测试的信号（=1表示完成）|
| `glOSCore1BarrierInitPhase` | Core1完成Core0 RAM测试及SBST的信号（=1表示完成）|
| `glOSCore0BarrierRunPhase` | Core0允许Core1进入正常运行的信号 |

这些变量通过 `#pragma section` 放置在特定的内存段，以确保多核可见性。

### 6.2 运行时安全机制

**SMU（Safety Management Unit）告警系统**

SMU 是 TC377 的核心安全模块，监控硬件安全。`InterruptHandler.c` 中的 `Trap7_ISR` 是 SMU 的 NMI（不可屏蔽中断）处理函数，负责：
- 读取并清除各 SMU 告警组（AG0~AG11）的告警标志
- 调用 `Fusa_increaseErrCnt` 增加对应错误计数
- 最终触发安全响应（告警计数达到阈值时降级/关机）

**MPU（Memory Protection Unit）**

`OS_MAIN` 中配置 MPU，实现：
- 代码段只读执行保护
- 数据段读写保护
- 不同 OS Application 之间的内存隔离

**任务看门狗（TaskWatchdog）**

位于 `Core1_ASIL_C/TaskWatchdog/`，监控各周期任务是否按时执行，超时触发安全响应。

**功能安全故障处理（FUSI_SWC）**

`Fusa_Fault_handling.c` 定义故障索引枚举（从 LBIST_ERR_INDEX 到 SMU 告警索引），实现故障确认、计数、安全降级的完整机制。

### 6.3 关断路径测试

`CDD_Safety/CDD_ShutoffPath/` 实现硬件关断路径的完整性测试，在 `CDD_Core1_Init` 中调用：

```c
ShutoffPath_Test_Finish = CDD_Shutoff_Path_Test_MainFunc();
```

验证从软件指令到 IGBT 关断的整个硬件链路是否有效。

## 8. 复杂设备驱动（CDD）

### 8.1 GD3162 栅极驱动（CDD_Safety/CDD_GD3162）

GD3162 是 NXP 的三相 SiC/IGBT 栅极驱动芯片，通过 SPI 与 MCU 通信，实现诊断和保护。

**初始化流程**（在 `CDD_Core1_Init` 中）：

```c
CDD_GD3162T_SPIInit();    // 初始化Top相的SPI通道
CDD_GD3162B_SPIInit();    // 初始化Bottom相的SPI通道
Spi_Init(&Spi_Config);    // AUTOSAR SPI初始化
CDD_GD3162_Init();        // GD3162芯片完整初始化（含BIST自检）
```

**主要接口**：

| 函数 | 功能 |
|------|------|
| `CDD_GD3162_Init()` | 芯片初始化（寄存器配置+BIST）|
| `CDD_GD3162_MainFunc()` | 周期主函数（诊断读取+故障处理）|
| `CDD_GD3162_BISTCheck()` | 内置自检 |
| `CDD_GD3162_GetSelfCheckRes()` | 获取自检结果 |
| `CDD_GD3162_PWM_State()` | 获取PWM输出状态 |
| `GD3162_Aout_App()` | 模拟量输出应用 |

**全局状态变量**：
- `GD3162_PWM_State`：当前PWM输出状态（0=关断，1=正常）
- `GD3162_SelfCheckState`：自检结果（E_OK=通过）
- `GD3162_SelfCheckErr`：自检错误码

### 8.2 TLF35584 系统基础芯片（CDD_Safety/CDD_TLF35584）

TLF35584 提供电源管理和系统安全功能：
- 为 MCU 提供调节好的电源轨（5V/3.3V/1.3V）
- 内置看门狗（Windows WDG + Functional WDG）
- 安全状态引脚（FSP，Fail Safe Pin）
- MPS（监控引脚）：由代码控制，用于TLF安全测试时序

启动阶段的 TLF35584 安全测试（`KRSTS_TLF35584Test_Init_Start`）验证 WDG 功能和安全状态转移的正确性。

### 8.3 电机控制软件（CDD_QM/MCS）

MCS（Motor Control Software）是 GTM/MCS（Micro Code Sequencer）驱动：

| 文件 | 功能 |
|------|------|

GTM（Generic Timer Module）是 TC377 的专用定时器，用于高精度 PWM 波形生成，ATOM 通道通过 MCS 实现与 ADC 采样的精确同步。

### 8.4 DSADC（CDD_Safety/CDD_DSADC）

基于 AscLin（ASCLIN Asynchronous/Synchronous Interface）外设实现 LIN 总线通信，`LIN_Sys_Init()` 在 `CDD_QM_Init` 中调用完成初始化。

## 11. 核间通信（IOC）

### 11.1 IOC 机制

TC377 多核之间的数据共享通过两种方式实现：

1. **IOC（Inter-OS-Application Communicator）**：AUTOSAR 标准机制，通过共享内存+同步原语实现类型安全的数据交换
   - `IOC_Core0/`：Core0发布/订阅的IOC通道
   - `IOC_Core1/`：Core1的IOC通道
   - `IOC_Core2/`：Core2的IOC通道

2. **自旋锁（Spinlock）**：
   - `Task_Spinlock_FUSA/`：FuSa通道的自旋锁（Core1安全数据写保护）
   - `Task_Spinlock_ASW/`：ASW通道的自旋锁（Core2控制数据写保护）

### 11.2 数据流方向

```
Core2 (FOC)          Core1 (Safety)         Core0 (VCU)
───────────          ──────────────         ───────────
实际电流Id/Iq   →   安全监控通道      ←→   扭矩设定值
实际转速        →   FUSI监控          ←   驾驶员需求
实际扭矩        →   比较判断          →   状态上报CAN
PWM状态         →   告警处理          ←   使能/禁止指令
```

  - TriCore 特有指令集使能（`-march=tc162`）
  - 功能安全相关的编译选项

## 15. 常用接口与调用规范

### 15.1 CDD 初始化顺序

```
上电复位
└── EcuM_Init
    ├── UserDefine_Init1
    │   └── IoHwAb_Adc_Init()             [ADC基础初始化]
    ├── UserDefine_Init2
    │   ├── Fee_Safety_Init()             [安全FEE初始化]
    │   ├── Fee_Safety_ReadAll()          [读取安全NVM]
    │   └── CDD_QM_Init()
    │       ├── gtm_init()                [GTM基础初始化]
    │       ├── CDD_GTM_TIM_Init()        [GTM TIM输入捕获]
    │       ├── Dsadc_Init()              [DSADC初始化]
    │       ├── gtm_mcs_Init()            [MCS初始化]
    │       ├── GtmAtom0Channel_Enable()  [使能PWM通道]
    │       ├── GCDD_Tlf35584_Init()      [TLF35584初始化]
    │       ├── LIN_Sys_Init()            [LIN初始化]
    │       └── MPU_Init()               [MPU保护初始化]
    └── UserDefine_Init3
        └── CDD_Core1_Init()
            ├── Aout_Tim_Icu_Init()       [模拟量定时器捕获]
            ├── IrqDma_Init()            [DMA中断配置]
            ├── IrqSpi_Init()            [SPI中断配置]
            ├── Dma_Init()               [DMA初始化]
            ├── CDD_GD3162T_SPIInit()    [GD3162 Top SPI]
            ├── CDD_GD3162B_SPIInit()    [GD3162 Bot SPI]
            ├── Spi_Init()               [AUTOSAR SPI]
            ├── CDD_GD3162_Init()        [栅极驱动初始化]
            └── CDD_Shutoff_Path_Test_MainFunc() [关断路径测试]
```

### 15.2 周期任务时序

| 任务周期 | 典型内容 |
|----------|----------|
| 25 µs（高速中断）| FOC电流环（Core2）、PWM更新、DSADC采样 |
| 100 µs | 速度计算、弱磁控制 |
| 1 ms | VCU控制任务（Core0）、CAN接收处理 |
| 10 ms | 故障检测、模式切换判断 |
| 100 ms | CAN发送、OBD、NVM写入、网络管理 |
| 1 s | 周期性自检（运行时安全监控）|

### 15.3 安全监控告警响应流程

```
SMU 硬件检测到异常
        ↓
触发 Trap7（NMI中断）
        ↓
Trap7_ISR() → 读取 SMU 告警组状态
        ↓
Fusa_increaseErrCnt(xxx_ERR_INDEX) → 错误计数+1
        ↓
错误计数达到 FUSA_COMFIRM_CNT (3次)
        ↓
执行安全响应（如：关断PWM输出、系统降级、复位）
```
