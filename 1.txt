## 1. FOC 整体架构

### 1.1 什么是 FOC

磁场定向控制（Field Oriented Control, FOC）通过坐标变换，将三相交流电机等效为直流电机进行控制：
- **d轴**：励磁轴（控制磁通量）
- **q轴**：转矩轴（控制输出扭矩）

控制目标：使 Id 跟随给定（基速区为0，弱磁区为负值），使 Iq 精确跟随扭矩指令。

### 1.2 完整控制回路

```
                    ┌─────────────────────────────────────────────────────┐
                    │                   Core2 FOC 控制回路                  │
                    │                                                       │
  转矩指令    ──►  扭矩/电流仲裁                                             │
  (来自Core0)       │                                                       │
                    ▼                                                       │
            Id_Ref, Iq_Ref  ◄── 弱磁控制 ◄── Udc / 转速                    │
                    │                                                       │
                    ▼                                                       │
         ┌─── 电流PI控制 ───┐                                               │
         │  Kp_d, Ki_d      │                                               │
         │  Kp_q, Ki_q      │                                               │
         └──────────────────┘                                               │
                    │ Ud_out, Uq_out                                        │
                    ▼                                                       │
              Park 逆变换（dq → αβ）                                         │
                    │ Ualpha, Ubeta                                         │
                    ▼                                                       │
              空间矢量调制（SVPWM）                                           │
                    │ DutyU, DutyV, DutyW                                  │
                    ▼                                                       │
              死区补偿 + PWM输出                                             │
                    │                                                       │
                    ▼                                                       │
              逆变器（IGBT/SiC）─── 三相电压 ──► 电机                        │
                    │                                ↑                     │
              三相电流采样（DSADC/ADC）──────────────┘                       │
                    │ Iu, Iv, Iw                                            │
                    ▼                                                       │
              Clarke变换（uvw → αβ）                                         │
                    │                                                       │
                    ▼                                                       │
              Park变换（αβ → dq）◄── 转子角θ                                 │
                    │ Id_Fb, Iq_Fb                                          │
                    └──────► 反馈至电流PI控制                                │
                                                                            │
  旋变信号 ──► RDC解码 ──► PLL位置观测器 ──► 转子角θ + 转速ω               │
                    │                                                       │
                    └─────────────────────────────────────────────────────┘
```

## 2. 任务调度与执行速率

FOC 采用多速率调度，不同控制环路运行在不同频率：

| 执行周期 | 频率 | 主要任务 |
|----------|------|----------|
| **25 µs（ISR）** | 40 kHz | ADC读取 → 旋变解码 → 坐标变换 → 电流PI → SVPWM → PWM输出、故障检测 |
| **500 µs** | 2 kHz | 弱磁控制更新、谐波控制更新 |
| **2 ms** | 500 Hz | 加热控制、直流侧估算 |
| **5 ms** | 200 Hz | 速度滤波、标定参数更新、涡流传感器辨识 |

> **注意**：工程实际 PWM 开关频率可配置为 10kHz 或 20kHz，ISR 触发周期随之变化（50µs 或 25µs），各模块的滤波器系数会随之动态调整。

## 3. ADC 采样与电流信息（AdcInfo_if）

### 3.1 功能概述

负责从 MCU ADC 外设读取相电流、直流母线电压、温度等模拟量，并完成零点校准和物理量换算。

### 3.2 关键数据结构

```c
// 相电流零点校准结构
typedef struct {
    float32 I_U_Offset;       // U相零点偏置（ADC counts）
    float32 I_V_Offset;       // V相零点偏置
    float32 I_W_Offset;       // W相零点偏置
} ADC_CURRENT_OFFSET;

// ADC原始值（零点校正后）
typedef struct {
    int16_T I_U;              // U相电流原始值
    int16_T I_V;
    int16_T I_W;
    uint16_T Udc;             // 直流母线电压原始值
} AdcRawVal;

// 物理量换算结果
typedef struct {
    float32 I_U;              // U相电流（A）
    float32 I_V;
    float32 I_W;
    float32 Udc;              // 直流母线电压（V）
    float32 Udc_Filt;         // 滤波后直流母线电压（V）
    float32 Temp_Motor1;      // 电机温度1（℃）
    float32 Temp_Motor2;
    float32 Temp_IGBT_U/V/W;  // 功率管温度
    // ... 其他模拟量
} AdcRealVal;

// 直流母线一阶低通滤波器状态
typedef struct {
    float32 Filt_Coeff;       // 滤波系数α
    float32 Filt_OutValue;    // 滤波器输出
    float32 Filt_LastValue;   // 上次输出值
} Filt_Struct;
```

### 3.3 关键函数详解

#### `ADC_Offset_Init()`
**作用**：初始化电流传感器零点，默认设为 2048（12bit ADC 中间值）。

```c
void ADC_Offset_Init(void)
{
    AdcOffset.I_U_Offset = 2048.0F;  // 12bit ADC中间值
    AdcOffset.I_V_Offset = 2048.0F;
    AdcOffset.I_W_Offset = 2048.0F;
}
```

#### `ADC_Read_Isr()`
**作用**：ISR 速率（25µs）采集相电流和直流母线电压。

```c
void ADC_Read_Isr(void)
{
    // 读取原始ADC并去零点偏置
    AdcRawVal.I_U = (int16_T)(ADC_raw_U - AdcOffset.I_U_Offset);
    AdcRawVal.I_V = (int16_T)(ADC_raw_V - AdcOffset.I_V_Offset);
    AdcRawVal.I_W = (int16_T)(ADC_raw_W - AdcOffset.I_W_Offset);

    // 换算为物理量（乘以增益系数）
    AdcRealVal.I_U = AdcRawVal.I_U * ADC_CURRENT_GAIN_U;
    AdcRealVal.I_V = AdcRawVal.I_V * ADC_CURRENT_GAIN_V;
    AdcRealVal.I_W = AdcRawVal.I_W * ADC_CURRENT_GAIN_W;

    // 直流母线电压：一阶低通滤波（α=0.001F，截止频率≈3Hz@20kHz）
    // y[n] = α*x[n] + (1-α)*y[n-1]
    UdcFilt.Filt_OutValue = UdcFilt.Filt_Coeff * Udc_Raw
                          + (1.0F - UdcFilt.Filt_Coeff) * UdcFilt.Filt_LastValue;
    UdcFilt.Filt_LastValue = UdcFilt.Filt_OutValue;
    AdcRealVal.Udc_Filt = UdcFilt.Filt_OutValue;
}
```

**关键参数**：
- 直流母线滤波系数 `α = 0.001F`，对应截止频率 ≈ 3 Hz（20kHz 基频）
- 相电流增益：每相独立配置（`ADC_CURRENT_GAIN_U/V/W`），补偿传感器差异

#### `CurrentSensorOffsetCalc05ms()`
**作用**：在电机静止时，每 5ms 累积 128 个采样做平均，在线自动更新电流零点。

```c
void CurrentSensorOffsetCalc05ms(void)
{
    static uint8 sampleCnt = 0;
    static float32 accU = 0, accV = 0, accW = 0;

    accU += ADC_raw_U;
    accV += ADC_raw_V;
    accW += ADC_raw_W;
    sampleCnt++;

    if (sampleCnt >= 128) {
        // 右移7位等价于除以128
        AdcOffset.I_U_Offset = accU >> 7;
        AdcOffset.I_V_Offset = accV >> 7;
        AdcOffset.I_W_Offset = accW >> 7;
        accU = accV = accW = 0;
        sampleCnt = 0;
    }
}
```

#### `ADC_Read_2ms()`
**作用**：2ms 速率读取慢变量（温度、辅助电压等）。

## 4. 旋变解码与转子位置（RDC_ReadOut_if）

### 4.1 功能概述

旋变（Resolver）是一种模拟式角度传感器，通过激励信号和返回信号的比值计算转子绝对位置。本模块完成：
1. 读取位置观测器输出的数字角度
2. 叠加旋变安装偏置角补偿
3. 叠加动态相位超前补偿（补偿Park变换延迟）
4. 支持主动加热模式下的角度锁定

### 4.2 关键数据结构

```c
typedef struct {
    int16_T  Angle_ReadOut;    // 原始读出角度（int16，范围-32768~32767对应-π~π）
    int16_T  Angle_s16;        // 补偿后角度（含偏置+相位超前）
    int16_T  AngleReal_s16;    // 最终实际角度（含方向修正）
    float32  ReslverOfst;      // 旋变安装偏置角（度，如44.2°）
    float32  CompTm;           // 相位超前补偿时间（s，如0.007542s）
    int8_T   RsvlDir;          // 旋变方向（+1 或 -1）
    uint8_T  PmDivPr;          // 电机极对数/旋变极对数（如3/3=1）
    uint8_T  EMH_AngleLockFlg; // 主动加热锁角标志
} RDC_Read_Struct_Type;
```

### 4.3 关键参数含义

| 参数 | 典型值 | 说明 |
|------|--------|------|
| `ReslverOfst` | 44.2° | 旋变安装偏差，通过标定写入NVM |
| `CompTm` | 0.007542 s | Park变换延迟补偿，用转速×时间补偿角度超前 |
| `RsvlDir` | ±1 | 旋变安装方向（顺/逆时针）|
| `PmDivPr` | 1（3/3）| 电机3极对数，旋变3极对数，比值为1 |

### 4.4 关键函数详解

#### `RDC_ReadOut_App_ISR()`
**作用**：ISR 速率完成旋变角度全链路处理。

```c
void RDC_ReadOut_App_ISR(void)
{
    // Step1: 读取位置观测器PLL输出的估计角度
    RDC_Read.Angle_ReadOut = PosDemSW.PosEst;  // int16格式，满量程=2π

    // Step2: 叠加旋变安装偏置补偿
    // 换算关系: 1度 = 182.044 counts（int16全范围65536对应360°）
    RDC_Read.Angle_s16 = RDC_Read.Angle_ReadOut
                       + (int16_T)(RDC_Read.ReslverOfst * 182.044F);

    // Step3: 叠加动态相位超前补偿（补偿Park变换的采样延迟）
    // 补偿量 = 转速(rpm) × 极对数 × 时间(s) × 换算系数
    // 物理含义：电机旋转过程中，控制周期内转过的角度
    RDC_Read.AngleReal_s16 = RDC_Read.Angle_s16
                           + (int16_T)(SpdCalcu.Spd_rpm_Flt
                                      * RDC_Read.PmDivPr
                                      * RDC_Read.CompTm
                                      * (182.044F / 60.0F));

    // Step4: 方向修正
    RDC_Read.AngleReal_s16 *= RDC_Read.RsvlDir;

    // Step5: 主动加热模式（EMH）- 锁定角度到固定扇区
    if (RDC_Read.EMH_AngleLockFlg) {
        // 将角度量化到0~10共11个离散位置
        // 目的：在加热时产生零转矩（纯d轴激励）
        int16_T sector = (RDC_Read.AngleReal_s16 >> 12) & 0x0F;
        // 锁定到该扇区的固定角度
        RDC_Read.AngleReal_s16 = HeatingSectorAngle[sector];
    }
}
```

**补偿原理图**：
```
实际角度 = 旋变原始角度 + 安装偏置 + 转速×延迟补偿
         = PLL输出      + 44.2°    + ω×0.007542s
```

## 5. 位置观测器PLL（PositionObsr_if）

### 5.1 功能概述

将旋变模拟信号经过 A/D 采样后，通过锁相环（PLL）算法估计转子位置和速度，实现数字化位置解算。

### 5.2 PLL 工作原理

```
旋变Sin信号 ─┐
              ├─► 解调 ─► 误差 e(θ) ─► PI控制器 ─► 积分 ─► 估计位置 PosEst
旋变Cos信号 ─┘                ▲                          │
                               └──────────────────────────┘
                                        反馈
```

### 5.3 关键数据结构

```c
typedef struct {
    int32_T  Omega;         // 估计角速度（int32，高精度）
    int16_T  ThetaErr;      // 位置误差
    int16_T  PosEst;        // 估计转子位置（int16，-32768~32767对应-π~π）
    float32  PLL_Coeff1;    // PLL积分系数
    float32  PLL_Coeff2;    // PLL比例系数
    float32  Integ_Coeff;   // 积分器系数
    float32  Kp;            // PLL比例增益
    float32  Ki;            // PLL积分增益
} POSDEMOD_STRUCT;
```

### 5.4 关键函数

#### `Pos_SWDemodulation()`
**作用**：PLL 核心算法，25µs ISR 执行。

```
// PLL 误差计算（叉积法）
ThetaErr = Sin_Est * Cos_Measured - Cos_Est * Sin_Measured
// ≈ sin(θ_est - θ_real) ≈ (θ_est - θ_real)（小角度近似）

// PI 更新角速度
Omega = Omega + Ki * ThetaErr

// 积分得到位置
PosEst = PosEst + Kp * ThetaErr + Integ_Coeff * Omega
```

## 6. 速度计算（Spd_Calcu_if）

### 6.1 功能概述

将 PLL 输出的角速度 Omega 转换为电机转速（rpm），并提供多个带宽不同的滤波输出，供不同控制环路使用。

### 6.2 关键数据结构

```c
typedef struct {
    float32 Fre_Hz;            // 基波电频率（Hz）
    float32 Spd_rpm;           // 原始转速（rpm，无滤波）
    float32 Spd_rpm_Flt;       // 低通滤波转速（约3Hz截止）
    float32 Spd_rpm_FltAbs;    // 滤波转速绝对值
    float32 Spd_rpm_HF;        // 高频滤波转速（约1Hz截止）
    float32 Spd_rpm_spdlop;    // 速度环专用滤波（约25Hz截止）
    float32 Spd_rpm_ACR;       // 电流控制用滤波（约10Hz截止）
    float32 Spd_rpm_Vehicle;   // 整车车速（来自轮速或CAN）
    float32 FreqToSpdCoe;      // 频率→转速换算系数（=60/极对数）
    int8_T  RsvlDir;           // 方向符号
} SpdCalu_Struct_Type;
```

### 6.3 滤波器设计

各滤波器系数（以20kHz开关频率为例）：

| 滤波器用途 | 系数α | 截止频率 |
|-----------|-------|----------|
| 基础低通（通用）| 0.0785 | ~250 Hz |
| 高频低通 | 0.0157 | ~50 Hz |
| 速度环 | 0.0079 | ~25 Hz |
| 电流控制用 | 0.0031 | ~10 Hz |

> 系数 α 随开关频率等比缩放：`α_new = α_base × (SwFreq_Apply / SwFreq_Base)`

### 6.4 关键函数详解

#### `SpdCalcu_App_ISR()`
**作用**：ISR 速率将角速度转为转速，并应用多级滤波。

```c
void SpdCalcu_App_ISR(void)
{
    // Step1: 从PLL观测器读取角速度，转换为电频率
    // Omega 为 int32 格式，15000 和 >>15 是定点数格式转换系数
    SpdCalcu.Fre_Hz = ((float32)(PosDemSW.Omega * 15000L >> 15)) * 0.1F;

    // Step2: 转换为转速 rpm
    // FreqToSpdCoe = 60 / PolePairs（3极对数时 = 20 rpm/Hz）
    SpdCalcu.Spd_rpm = SpdCalcu.Fre_Hz * SpdCalcu.FreqToSpdCoe * SpdCalcu.RsvlDir;

    // Step3: 多路并行低通滤波（一阶IIR）
    // y[n] = α*x[n] + (1-α)*y[n-1]
    SpdCalcu.Spd_rpm_Flt    = FLT_COEFF_BASE * SpdCalcu.Spd_rpm
                             + (1.0F - FLT_COEFF_BASE) * SpdCalcu.Spd_rpm_Flt;

    SpdCalcu.Spd_rpm_spdlop = FLT_COEFF_SPDLOP * SpdCalcu.Spd_rpm
                             + (1.0F - FLT_COEFF_SPDLOP) * SpdCalcu.Spd_rpm_spdlop;

    SpdCalcu.Spd_rpm_ACR    = FLT_COEFF_ACR * SpdCalcu.Spd_rpm
                             + (1.0F - FLT_COEFF_ACR) * SpdCalcu.Spd_rpm_ACR;

    // 绝对值
    SpdCalcu.Spd_rpm_FltAbs = fabsf(SpdCalcu.Spd_rpm_Flt);
}
```

#### `SpdCalcu_App_5ms()`
**作用**：5ms 速率处理整车车速，支持轮速或 CAN 信号的有效性仲裁。

```c
// 整车速度换算（rpm → km/h）
// 以 C10 车型为例：传动比 85.99，轮胎周长按轮径计算
Spd_rpm_Vehicle = Spd_rpm_Flt / GearRatio × WheelCircumference × (60/1000)
```

## 7. 坐标变换（CoordinateTrans_if）

### 7.1 功能概述

实现 FOC 的核心坐标变换链路：
- **Clarke 变换**：三相电流（Iu, Iv, Iw）→ 两相静止坐标（Iα, Iβ）
- **Park 变换**：两相静止坐标（Iα, Iβ）→ 两相旋转坐标（Id, Iq）

### 7.2 关键数据结构

```c
typedef struct {
    // 三相电流输入
    float32 Iu, Iv, Iw;

    // αβ 静止坐标系（Clarke输出）
    float32 Ialpha, Ibeta;

    // dq 旋转坐标系（Park输出）
    float32 Id, Iq;

    // 电流合矢量极坐标
    float32 IsMag;           // 电流幅值 = √(Ialpha² + Ibeta²)
    int16_T IsThetaINT;      // 电流矢量角度（int16格式）
    float32 IsThetaRAD;      // 电流矢量角度（弧度）

    // 滤波后的dq轴电流反馈
    float32 IdFbk_Flt;       // d轴滤波电流（供PI使用）
    float32 IqFbk_Flt;       // q轴滤波电流

    // Park变换的三角函数值（来自转子角度）
    int32_T Sin_Pos;         // sin(θ)（定点，高16位为整数部分）
    int32_T Cos_Pos;         // cos(θ)
} MOTORCURRENT_STRUCT;
```

### 7.3 关键函数详解

#### `IUVW2DQTrans()`
**作用**：完成完整的相电流 → dq 变换链路。

**Clarke 变换公式**（等幅值变换）：

```
Iα = Iu
Iβ = (Iv - Iw) / √3
   = (Iu + 2×Iv) / √3   ← 利用Iu+Iv+Iw=0化简
```

**Park 变换公式**：

```
Id = Iα × cos(θ) + Iβ × sin(θ)
Iq = -Iα × sin(θ) + Iβ × cos(θ)
```

**代码实现要点**：

```c
void IUVW2DQTrans(void)
{
    // === Step1: 获取相电流（含传感器容错逻辑）===
    // 正常情况：直接读 Iu, Iv, Iw
    // 单相故障：由其他两相计算（如 Iw = -Iu - Iv）
    MotorCurrent.Iu = AdcRealVal.I_U;
    MotorCurrent.Iv = AdcRealVal.I_V;
    MotorCurrent.Iw = AdcRealVal.I_W;

    // === Step2: Clarke 变换 ===
    MotorCurrent.Ialpha = MotorCurrent.Iu;
    // √3/3 ≈ 0.57735F，等幅值变换系数
    MotorCurrent.Ibeta = (MotorCurrent.Iv - MotorCurrent.Iw) * 0.57735F;

    // === Step3: 读取转子角度的正弦/余弦值（定点查表）===
    // GFLIB_Sin/Cos 返回 int32_T，Q15 格式（范围 ±32767）
    MotorCurrent.Sin_Pos = GFLIB_Sin(RDC_Read.AngleReal_s16);
    MotorCurrent.Cos_Pos = GFLIB_Cos(RDC_Read.AngleReal_s16);

    // 转换为浮点：INT2REAL = 1/32768 = 3.0517578e-5F
    float32 sinTheta = MotorCurrent.Sin_Pos * INT2REAL;
    float32 cosTheta = MotorCurrent.Cos_Pos * INT2REAL;

    // === Step4: Park 变换 ===
    MotorCurrent.Id = MotorCurrent.Ialpha * cosTheta
                    + MotorCurrent.Ibeta  * sinTheta;
    MotorCurrent.Iq = -MotorCurrent.Ialpha * sinTheta
                    + MotorCurrent.Ibeta   * cosTheta;

    // === Step5: 一阶低通滤波（供PI反馈使用）===
    // α = CalIsFbkFltCoff = 0.00628F（截止频率约20Hz@20kHz）
    MotorCurrent.IdFbk_Flt = LPF_COEFF * MotorCurrent.Id
                           + (1.0F - LPF_COEFF) * MotorCurrent.IdFbk_Flt;
    MotorCurrent.IqFbk_Flt = LPF_COEFF * MotorCurrent.Iq
                           + (1.0F - LPF_COEFF) * MotorCurrent.IqFbk_Flt;
}
```

#### `Ialfbet2Polar()`
**作用**：计算电流矢量的幅值和角度（极坐标形式）。

```c
// 幅值：IsMag = √(Iα² + Iβ²)
MotorCurrent.IsMag = sqrtf(MotorCurrent.Ialpha * MotorCurrent.Ialpha
                          + MotorCurrent.Ibeta  * MotorCurrent.Ibeta);

// 角度：IsThetaINT = atan2(Iβ, Iα)（定点格式）
MotorCurrent.IsThetaINT = GFLIB_AtanYX(MotorCurrent.Ibeta, MotorCurrent.Ialpha);
MotorCurrent.IsThetaRAD = MotorCurrent.IsThetaINT * INT2RAD;
// INT2RAD = 2π/65536 = 9.58738E-5F
```

### 9.4 关键函数详解

#### `CurntCtrl_ISR()` — PI 控制核心算法

```c
void CurntCtrl_ISR(void)
{
    // === Step1: 计算误差 ===
    float32 err_d = CurCtrl.Id_Ref - CurCtrl.Id_Fb;
    float32 err_q = CurCtrl.Iq_Ref - CurCtrl.Iq_Fb;

    // === Step2: 计算最大电压约束 ===
    // MaxVoltCoeff = 0.585F（典型），SVPWM最大输出 = Udc/√3
    CurCtrl.Us_Max = CurCtrl.Udc * MaxVoltCoeff;
    // Us_Max 典型值：600V × 0.585 ≈ 351V（电网基波幅值限制）

    // === Step3: PI 计算（含解耦前馈）===
    // d轴 PI 输出（纯PI，不含解耦）
    float32 Ud_PI = CurCtrl.Kp_d * err_d + CurCtrl.Integ_d;

    // q轴 PI 输出（纯PI，不含解耦）
    float32 Uq_PI = CurCtrl.Kp_q * err_q + CurCtrl.Integ_q;

    // === Step4: 电压矢量饱和限幅 ===
    // 电压矢量幅值 = √(Ud² + Uq²)
    float32 Us_Mag = sqrtf(Ud_PI * Ud_PI + Uq_PI * Uq_PI);

    if (Us_Mag > CurCtrl.Us_Max) {
        // 等比例缩放，保持电压矢量方向不变
        float32 scale = CurCtrl.Us_Max / Us_Mag;
        CurCtrl.Ud_out = Ud_PI * scale;
        CurCtrl.Uq_out = Uq_PI * scale;
        CurCtrl.SatFlag = 1;  // 置饱和标志
    } else {
        CurCtrl.Ud_out = Ud_PI;
        CurCtrl.Uq_out = Uq_PI;
        CurCtrl.SatFlag = 0;
    }

    // === Step5: 积分更新（含抗饱和）===
    if (!CurCtrl.SatFlag) {
        // 未饱和：正常积分
        CurCtrl.Integ_d += CurCtrl.Ki_d * err_d;
        CurCtrl.Integ_q += CurCtrl.Ki_q * err_q;
    } else {
        // 饱和时：反向回馈抑制积分（Clamping + Back-Calculation）
        // aw = KawCoeff × (Ud_out - Ud_PI)
        CurCtrl.Integ_d += CurCtrl.Ki_d * err_d
                         + CurCtrl.KawCoeff * (CurCtrl.Ud_out - Ud_PI);
        CurCtrl.Integ_q += CurCtrl.Ki_q * err_q
                         + CurCtrl.KawCoeff * (CurCtrl.Uq_out - Uq_PI);
    }

    // === Step6: 记录输出矢量信息 ===
    CurCtrl.Us_MagApply = sqrtf(CurCtrl.Ud_out * CurCtrl.Ud_out
                               + CurCtrl.Uq_out * CurCtrl.Uq_out);
    CurCtrl.Us_ThetaOut = atan2f(CurCtrl.Uq_out, CurCtrl.Ud_out);
}
```

### 9.5 PI 参数物理含义

| 参数 | 典型值（20kHz）| 物理含义 |
|------|----------------|----------|
| `Kp_d` | 0.38 × 2.0 = 0.76 | d轴比例增益（越大响应越快，但可能振荡）|
| `Ki_d` | 0.003 × 1.2 × 2.0 = 0.0072 | d轴积分增益（消除稳态误差）|
| `Kp_q` | 0.56 × 2.0 = 1.12 | q轴比例增益（q轴需更快响应扭矩变化）|
| `KawCoeff` | 0.75 | 抗饱和强度（越大抗饱和越强，积分衰减越快）|
| `MaxVoltCoeff` | 0.585 | 电压利用率（≈1/√3，SVPWM理论最大为1/√3≈0.577）|

## 10. 弱磁控制（FluxWeaken_if）

### 10.1 功能概述

当电机转速超过基速时，反电动势超过逆变器能提供的最大电压，此时需要注入负 d 轴电流（Id < 0）来削弱气隙磁场（弱磁），以维持对 q 轴电流的控制能力，实现扩速运行。

### 10.2 基速与弱磁区划分

```
        扭矩
          ↑
   最大扭矩│───────────── MTPA区 ─────────────┐
          │                                   │  弱磁区
          │                                   └──────────────────
          │                                   基速                 → 转速
          0

基速区（MTPA）：Id = 0 或 MTPA优化值，Iq = 扭矩/扭矩系数
弱磁区：    Id < 0（注入负d电流），|Ud² + Uq²| ≤ Us_Max²
```

### 10.3 关键数据结构

```c
typedef struct {
    // 电压限制系数（决定弱磁深度）
    float32 MaxVoltCoeff;      // 最大电压系数（0.585F）
    float32 MaxVoltCoeff2;     // 辅助系数

    // 工作点查表输出（Id/Iq的最优参考）
    float32 IdLUT;             // 查表得到的Id参考
    float32 IqLUT;             // 查表得到的Iq参考

    // 速度区间参数
    float32 Spd_FltAbs;        // 当前绝对转速
    float32 Spd_Turn;          // 弱磁起始转速
    float32 Spd_Max;           // 最高转速

    // 三路积分器（用于平滑轨迹过渡）
    float32 Integ_L1;          // 第1路积分器状态
    float32 Integ_L2;          // 第2路积分器状态
    float32 Integ_L3;          // 第3路积分器状态

    // 最终输出
    float32 IdSetFnl;          // 最终d轴电流设定值（A）
    float32 IqSetFnl;          // 最终q轴电流设定值（A）

    // MTPA角度过渡
    float32 ThetaInit;         // 初始角度
    float32 ThetaDelta;        // 角度增量
    float32 ThetaFinal;        // 最终角度（滤波后）
} FWCTRL_STRUCT;
```

### 10.4 关键函数详解

#### `FWCtrlAppNew_500us()` — 弱磁主控制循环（500µs）

```c
void FWCtrlAppNew_500us(void)
{
    // Step1: 从工作点查找表读取最优电流参考（MTPA曲线）
    // 查表输入：当前转速、扭矩指令
    // 查表输出：最优的Id和Iq设定值（在效率最优曲线上）
    FWCtrl.IdLUT = LookupTable_Id(SpdCalcu.Spd_rpm_Flt, TorqueCmd);
    FWCtrl.IqLUT = LookupTable_Iq(SpdCalcu.Spd_rpm_Flt, TorqueCmd);

    // Step2: 计算可用电压余量
    float32 Uavail = FWCtrl.MaxVoltCoeff * AdcRealVal.Udc_Filt;

    // Step3: 判断是否需要弱磁
    if (SpdCalcu.Spd_rpm_FltAbs > FWCtrl.Spd_Turn) {
        // 弱磁区：调整Id使电压约束满足
        // 原理：减小Id → 减小磁链 → 减小反电动势 → 电压余量恢复
        float32 Uout_Mag = CurCtrl.Us_MagApply;
        float32 VoltError = Uavail - Uout_Mag;  // 电压余量

        // 积分弱磁（PI控制器的积分项）
        FWCtrl.Integ_L1 += Ki_FW * VoltError;

        // Id限制在负值范围
        FWCtrl.IdSetFnl = CLAMP(FWCtrl.IdLUT + FWCtrl.Integ_L1,
                                Id_Min, 0.0F);
    } else {
        // 基速区：使用查表值（MTPA）
        FWCtrl.IdSetFnl = FWCtrl.IdLUT;
        FWCtrl.Integ_L1 = 0.0F;  // 清积分
    }

    // Step4: MTPA角度平滑过渡（三阶积分器）
    // 防止Id/Iq设定点突变引起冲击
    FWCtrl.ThetaDelta = ThetaTarget - FWCtrl.ThetaInit;
    FWCtrl.Integ_L2 += coeff2 * FWCtrl.ThetaDelta;
    FWCtrl.Integ_L3 += coeff3 * FWCtrl.Integ_L2;
    FWCtrl.ThetaFinal = FWCtrl.ThetaInit + FWCtrl.Integ_L3;

    // Step5: 输出最终q轴电流设定值
    FWCtrl.IqSetFnl = FWCtrl.IqLUT;  // （q轴由扭矩需求直接决定）
}
```

**弱磁控制原理简图**：
```
      高速运行
          │
    电压饱和（|Ud²+Uq²| > Us_Max²）
          │
    减小 Id（注入负d电流）
          │
    磁链减小 → 反电动势降低
          │
    电压余量恢复 → q轴控制能力恢复
          │
    维持扭矩输出
```

### 11.3 关键函数详解

#### `SVM()` — SVPWM 主函数

SVPWM 将电压矢量分解为相邻的两个有效电压矢量和零矢量：

```
六边形中的8个基本矢量：
       V3(010)
      /       \
V4(011)         V2(110)
  |       V0    |
  |      V7     |
V5(001)         V1(100)
      \       /
       V6(101)
```

**SVPWM计算步骤**：

```c
void SVM(void)
{
    // Step1: Park逆变换（dq → αβ）
    float32 sinTheta = GFLIB_Sin(VoltModu.RotorTheta) * INT2REAL;
    float32 cosTheta = GFLIB_Cos(VoltModu.RotorTheta) * INT2REAL;

    SVMnOVM.Ualpha = CurCtrl.Ud_out * cosTheta - CurCtrl.Uq_out * sinTheta;
    SVMnOVM.Ubeta  = CurCtrl.Ud_out * sinTheta + CurCtrl.Uq_out * cosTheta;

    // Step2: 计算电压矢量相角和调制指数
    SVM7_UsPhaseCalc();   // 计算PhaseUs（atan2(Ubeta, Ualpha)）
    SVM7_MICalc();        // 计算MI = |Us| / (Udc/√3)

    // Step3: 判断调制区域，选择不同调制方式
    if (SVMnOVM.MI <= MI_SVM_MAX) {
        SVMnOVM.SVMZone = 0;
        SVM7_SVMzoom();    // 线性SVPWM区（MI ≤ 1.0，最大电压利用率57.7%）
    } else if (SVMnOVM.MI <= MI_OVM1_MAX) {
        SVMnOVM.SVMZone = 1;
        SVM7_OVMzoom1();   // 过调制区1（部分六拍波）
    } else {
        SVMnOVM.SVMZone = 2;
        SVM7_OVMzoom2();   // 过调制区2（完整六拍方波）
    }

    // Step4: 计算最终三相占空比
    SVM7_DutyCalc();
}
```

**SVM7_SVMzoom() 扇区计算**：

```c
void SVM7_SVMzoom(void)
{
    // 确定扇区（0°~60°为扇区1，依次类推）
    SVMnOVM.SecNum = (uint8_T)(SVMnOVM.PhaseUs / (PI / 3));  // 0~5

    // 计算扇区内余角
    SVMnOVM.PhaseRem = SVMnOVM.PhaseUs - SVMnOVM.SecNum * (PI / 3);

    // 计算两个有效矢量的作用时间
    // T1 = MI * sin(60° - PhaseRem) / sin(60°)
    SVMnOVM.T1 = SVMnOVM.MI * sinf(PI/3 - SVMnOVM.PhaseRem) / sinf(PI/3);

    // T2 = MI * sin(PhaseRem) / sin(60°)
    SVMnOVM.T2 = SVMnOVM.MI * sinf(SVMnOVM.PhaseRem) / sinf(PI/3);

    // T0 = 1 - T1 - T2（零矢量时间）
    SVMnOVM.T0 = 1.0F - SVMnOVM.T1 - SVMnOVM.T2;
}
```

**SVM7_DutyCalc() 占空比计算**：

根据扇区和矢量作用时间，查表确定三相PWM占空比（7段式SVPWM）：

```c
void SVM7_DutyCalc(void)
{
    float32 t0_half = SVMnOVM.T0 / 2.0F;

    // 以扇区1（0°~60°，矢量V1+V2）为例：
    // U相：T0/2 + T1 + T2（最高占空比）
    // V相：T0/2 + T2
    // W相：T0/2（最低占空比）
    // 实际按扇区查表映射 U/V/W 对应关系

    // 归一化到 [0, 1]（T0/2在中心，上下各T0/4）
    SVMnOVM.DutyU = t0_half + T_high_U;
    SVMnOVM.DutyV = t0_half + T_high_V;
    SVMnOVM.DutyW = t0_half + T_high_W;

    // 写回到VOLTMOD输出
    VoltModu.UaM = SVMnOVM.DutyU;
    VoltModu.UbM = SVMnOVM.DutyV;
    VoltModu.UcM = SVMnOVM.DutyW;
}
```

**7段SVPWM 时序示意（扇区1）**：
```
PWM载波周期:  |  T0/4  |  T1/2  |  T2/2  | T0/2 |  T2/2  |  T1/2  |  T0/4  |
U相高电平:         ───────────────────────────────────────────────────
V相高电平:                   ─────────────────────────────
W相高电平:                              ──────────
```

## 12. 死区补偿（DeadBandComp_if）

### 12.1 功能概述

逆变器上下管切换时，为防止直通短路，需插入死区时间（约 2µs）。死区期间，实际施加到电机的电压与理论值有偏差，在低速时尤为明显，导致电流波形畸变和扭矩脉动。死区补偿通过在占空比上叠加补偿量来消除该误差。

### 12.2 关键数据结构

```c
typedef struct {
    int16_T RotorTheta;        // 当前转子位置
    float32 IsMag;             // 电流矢量幅值（用于判断补偿强度）
    float32 IsMagMin;          // 触发补偿的最小电流幅值（防抖）
    uint16_T DBTs;             // 死区时间（定时器ticks，典型400 ticks @ 20kHz = 2µs）
    float32 DBCompTs;          // 死区补偿量（时间，s）
    float32 CompU;             // U相补偿量（占空比，-1~1）
    float32 CompV;             // V相补偿量
    float32 CompW;             // W相补偿量
    float32 ThetaHys;          // 相电流过零检测迟滞角度
    float32 ThetaHysShift;     // 迟滞移位
} DBCOMP_STRUCT;
```

### 12.3 补偿原理

```
实际电压误差 = 死区时间 × Udc / PWM周期 × sign(I相)
补偿量 = -误差（反向补偿）

I相 > 0：下管关闭时间延长 → 实际电压偏低 → 补偿为正（增大占空比）
I相 < 0：上管关闭时间延长 → 实际电压偏高 → 补偿为负（减小占空比）
```

### 12.4 关键函数

#### `DBComp_3PhsComp()`

```c
void DBComp_3PhsComp(void)
{
    // 死区补偿时间（归一化到[0,1]范围）
    // DBCompTs = DBTs / PWM_Period_Ticks
    float32 compValue = DBComp.DBCompTs;  // ≈ 400/50000 = 0.008（20kHz时）

    // 根据相电流符号决定补偿方向
    // 使用转子角度和电流角度关系判断各相电流方向
    // （避免直接用ADC值判断，减少噪声影响）
    float32 phaseAngle_U = MotorCurrent.IsThetaRAD;
    float32 phaseAngle_V = phaseAngle_U - 2.0F * PI / 3.0F;
    float32 phaseAngle_W = phaseAngle_U + 2.0F * PI / 3.0F;

    // 含迟滞的符号判断（防止过零点附近频繁切换）
    DBComp.CompU = -compValue * SignWithHysteresis(sinf(phaseAngle_U),
                                                    DBComp.ThetaHys);
    DBComp.CompV = -compValue * SignWithHysteresis(sinf(phaseAngle_V),
                                                    DBComp.ThetaHys);
    DBComp.CompW = -compValue * SignWithHysteresis(sinf(phaseAngle_W),
                                                    DBComp.ThetaHys);
}
```

## 13. PWM输出（PWM_OutputSwitch_if）

### 13.1 功能概述

将 SVPWM 计算得到的占空比（0~1浮点数）转换为硬件定时器值，写入 GTM ATOM 通道，实现三相 PWM 波形输出，并管理 PWM 的使能/禁止。

### 13.2 关键数据结构

```c

    float32 SwFreq_Set_kHz;     // 设定开关频率（kHz，10 或 20）
    float32 SwFreq_Apply_kHz;   // 实际使用频率
    uint32  Prd_Ticks;          // PWM 载波半周期（ticks）
                                // 20kHz：50000 ticks（100MHz/20kHz/2/2）
                                // 10kHz：100000 ticks

    // 最终PWM定时器值（ticks）

    float32 MaxDuty;            // 最大占空比（1 - MinDuty）
} DUTYSEND_STRUCT;
```

### 13.3 关键函数详解

#### `PWM_OutputSwitch_App_ISR()` — PWM更新主函数

```c
void PWM_OutputSwitch_App_ISR(void)
{
    // Step1: 读取SVPWM输出的占空比（含死区补偿）
    DutySend.duty_U = VoltModu.UaM + DBComp.CompU;
    DutySend.duty_V = VoltModu.UbM + DBComp.CompV;
    DutySend.duty_W = VoltModu.UcM + DBComp.CompW;

    // Step2: 限幅（确保不超出有效范围）
    DutySend.duty_U = CLAMP(DutySend.duty_U, DutySend.MinDuty, DutySend.MaxDuty);
    DutySend.duty_V = CLAMP(DutySend.duty_V, DutySend.MinDuty, DutySend.MaxDuty);
    DutySend.duty_W = CLAMP(DutySend.duty_W, DutySend.MinDuty, DutySend.MaxDuty);

    // Step3: 转换为定时器ticks
    // 中心对齐PWM：比较值 = 半周期 × 占空比
    DutySend.Duty_U_Real = (uint32)(DutySend.Prd_Ticks * DutySend.duty_U);
    DutySend.Duty_V_Real = (uint32)(DutySend.Prd_Ticks * DutySend.duty_V);
    DutySend.Duty_W_Real = (uint32)(DutySend.Prd_Ticks * DutySend.duty_W);

    // Step4: 写入GTM硬件寄存器（实际PWM更新）
    PWM_duty_set(PHASE_U, DutySend.Duty_U_Real);
    PWM_duty_set(PHASE_V, DutySend.Duty_V_Real);
    PWM_duty_set(PHASE_W, DutySend.Duty_W_Real);

    // Step5: ADC采样触发点同步（在PWM谷值处触发）
    // 确保ADC采样在电流最稳定时刻进行
}
```

### 14.3 关键函数详解

#### `HarmonicCtrlApp_05ms()` — 谐波补偿参数更新（5ms）

```c
void HarmonicCtrlApp_05ms(void)
{
    // Step1: 判断是否满足谐波抑制激活条件
    float32 fre_Hz = SpdCalcu.Fre_Hz;
    float32 Udc    = AdcRealVal.Udc_Filt;
    float32 Trq    = TorqueCmd;

    bool speedOk = (fre_Hz > HmncsCtrl.SpdLow_Thre) &&
                   (fre_Hz < HmncsCtrl.SpdHigh_Thre);
    bool voltOk  = (Udc < HmncsCtrl.VoltThre);
    bool trqOk   = (fabsf(Trq) > HmncsCtrl.TrqThre);

    // Step2: 满足条件时从2D查找表插值谐波补偿量
    if (speedOk && voltOk && trqOk) {
        // 查表：以转速(rpm)和扭矩(Nm)为索引
        HmncsCtrl.Hmncs_Mag_Pos6th = LUT2D_Magnitude(fre_Hz * 60 / PolePairs, Trq);
        HmncsCtrl.Hmncs_Pha_Pos6th = LUT2D_Phase(fre_Hz * 60 / PolePairs, Trq);
    } else {
        // 不满足条件：谐波补偿量渐变归零（平滑切换）
        HmncsCtrl.Hmncs_Mag_Pos6th *= FADE_COEFF;
    }
```

```c
void HarmonicCtrlApp_ISR(void)

    CurCtrl.Iq_Ref += HmncsCtrl.qAxisRpl_Ref_6th;
}
```

## 15. 直流母线电流估算（IdcEstimation_if）

### 15.1 功能概述

由三相相电流和 PWM 占空比重构直流母线电流，用于：
- 计算电机输入功率（P = Udc × Idc）
- 过流保护
- 避免直接安装直流侧电流传感器（降成本）

### 15.2 估算原理

在 PWM 瞬间，直流母线电流等于导通相的相电流之和（加权平均）：

```
Idc = duty_U × Iu + duty_V × Iv + duty_W × Iw
    （精确计算需考虑死区效应修正）
```

### 15.3 关键数据结构

```c
typedef struct {
    // 相电流历史（k, k-1, k-2时刻）
    float32 Ia_k, Ia_k1, Ia_k2;
    float32 Ib_k, Ib_k1, Ib_k2;
    float32 Ic_k, Ic_k1, Ic_k2;

    // 占空比历史
    float32 dutyUset_k, dutyUset_k1, dutyUset_k2;
    float32 dutyVset_k, dutyVset_k1, dutyVset_k2;
    float32 dutyWset_k, dutyWset_k1, dutyWset_k2;

    // 估算结果
    float32 Idc_Est;          // 估算直流电流（A）
    float32 Idc_EstLpf;       // 低通滤波后（约100Hz截止）
    float32 Power;            // 瞬时功率（W）
    float32 PowerLpf;         // 滤波功率（W）

    // 参数
    float32 PwmPrd;           // PWM周期（s）
    float32 DandBand;         // 死区时间（s）
} IDCEST_STRUCT;
```

### 15.4 关键函数

#### `IdcEstApp_ISR()`

```c
void IdcEstApp_ISR(void)
{
    // 更新历史数据
    IdcEst.Ia_k2 = IdcEst.Ia_k1; IdcEst.Ia_k1 = IdcEst.Ia_k;
    IdcEst.Ia_k  = AdcRealVal.I_U;
    // ... 同理更新 Ib, Ic, dutyU/V/W

    // 估算Idc（加权重构）
    IdcEst.Idc_Est = IdcEst.dutyUset_k1 * IdcEst.Ia_k1
                   + IdcEst.dutyVset_k1 * IdcEst.Ib_k1
                   + IdcEst.dutyWset_k1 * IdcEst.Ic_k1;

    // 低通滤波（α = CalIdcEstFltCoff ≈ 0.00314F，约100Hz@20kHz）
    IdcEst.Idc_EstLpf += CalIdcEstFltCoff * (IdcEst.Idc_Est - IdcEst.Idc_EstLpf);

    // 功率计算
    IdcEst.Power    = AdcRealVal.Udc_Filt * IdcEst.Idc_Est;
    IdcEst.PowerLpf = AdcRealVal.Udc_Filt * IdcEst.Idc_EstLpf;
}
```

## 16. 系统加热（System_Heating）

### 16.1 功能概述

低温环境下，电池需要加热以提高充放电效率和安全性。通过向电机注入 **负 d 轴电流**（Id < 0，不产生转矩的磁化电流），在电机绕组电阻上产生热量，间接加热电池冷却液（或直接加热电机）。

### 16.2 加热级别与电流映射

| 加热级别 | 注入 Id（A）| 产热功率（估算） |
|----------|-------------|-----------------|
| Level 5 | -330 A | 最大加热（高功率）|
| Level 4 | -320 A | |
| Level 3 | -295 A | |
| Level 2 | -260 A | |
| Level 1 | -210 A | 低功率加热 |
| Level 0 | 0 A | 停止加热 |

### 16.3 关键函数详解

#### `HeatingForACRApp_2ms()` — 加热控制（2ms）

```c
void HeatingForACRApp_2ms(void)
{
    // Step1: 读取整车请求的加热级别（来自Core0 VCU）
    Heating.Heat_Level_CANin = HeatingCtrl_Arbit.gHeatLvl;

    // Step2: 级别→电流设定映射
    switch (Heating.Heat_Level_CANin) {
        case 5: Heating.IdInjSet = HEAT_ISLVLFIVE;  // -330.0A
                break;
        case 4: Heating.IdInjSet = -320.0F;  break;
        case 3: Heating.IdInjSet = -295.0F;  break;
        case 2: Heating.IdInjSet = -260.0F;  break;
        case 1: Heating.IdInjSet = -210.0F;  break;
        default:Heating.IdInjSet = 0.0F;     break;
    }

    // Step3: 安全检查
    if (Heating.ErrLevel >= ERR_LV1) {
        // 故障时立即停止加热
        Heating.IdInjSet = 0.0F;
        Heating.HeatEnable_En = FALSE;
    }

    // Step4: 输出到电流仲裁
    if (Heating.HeatEnable_En && Heating.Sytem_En) {
        // 注入d轴电流（负值，纯磁化，不产生转矩）
        // q轴电流仍由转矩指令决定（通常加热时Iq=0）
        CurCmdArbit.IdHeat = Heating.IdInjSet;
    }
}
```

**加热原理**：
```
注入 Id = -300A（负d轴）
↓
电流在电机三相绕组中产生热量
Q = I² × R_phase × t
↓
热量通过冷却液传导至电池
↓
电池温度升高，低温性能改善
```

## 17. 涡流位置传感器辨识（EddyCurPos）

### 17.1 功能概述

涡流位置传感器（Eddy Current Position Sensor）是旋变传感器的替代/备用方案。该模块通过 **递推最小二乘（RLS）在线辨识**，自动标定传感器的增益（m）、偏置（k）和相位（Pha）参数，无需人工标定。

### 17.2 状态机

```
IDLE(0) ──[使能]──► IDENT(1)──[3s辨识]──► CHECK(2)──[合格]──► CONVERGENCE(3)
   ▲                                │                              │
   └──────────────────────[不合格]──┘                              │
                                    └──────────────────────► FAIL(4)
```

### 17.3 关键函数

#### `EddyCurPos_ISR_Ident()` — RLS辨识核心（ISR速率）

```c
void EddyCurPos_ISR_Ident(void)
{
    // 辨识目标：sin/cos传感器输出模型
    // y = m * sin(θ + pha) + k
    // 在线辨识参数 [m, k, pha]

    // 辨识条件：电机稳速运行（2000rpm ± 20rpm）
    if (fabsf(SpdCalcu.Spd_rpm - 2000.0F) < 20.0F) {
        // 执行RLS迭代更新

        RLS_Update(&EddyCurPos.Cos_Para, EddyCurPos.Cos_Corr_In);

        if (EddyCurPos.IdentTimeCnt >= IDENT_TIME_COUNTS) {  // 3秒

        }
    }
}
```

## 18. 故障保护（MCS_Fault_Protect_if）

### 18.1 功能概述

MCS（Motor Control Software，即 GTM MCS 微代码序列器）负责硬件层面的过流/过压保护，本模块实现 MCU 侧的故障信号解析和响应。

### 18.2 关键数据结构

```c
typedef struct {
    // MCS → APP 方向（硬件告警信号）
    uint8_T OC_U, OC_V, OC_W;        // 各相过流（Over Current）
    uint8_T OC_U_Level, OC_V_Level, OC_W_Level; // 实时过流水平
    uint8_T OC_U_State, OC_V_State, OC_W_State; // 锁存过流状态

    uint8_T OV_Vdc;                   // 母线过压（Over Voltage）
    uint8_T D_UVLO;                   // 欠压锁定（Under Voltage Lock Out）
    uint8_T Drive_Fault_T;            // 顶管栅极驱动故障
    uint8_T Drive_Fault_B;            // 底管栅极驱动故障

    // APP → MCS 方向（控制命令）
    uint8_T PWM_Enable;               // PWM使能命令
    uint8_T Fault_Clear;              // 故障清除命令

    // 总线数据（32bit打包）

```

### 18.3 关键函数详解

#### `MCS_Fault_ProtectApp_ISR()` — ISR速率故障处理

```c
void MCS_Fault_ProtectApp_ISR(void)
{
    // Step1: 读取MCS硬件总线故障字
    MCSFault.MCS_To_APP_Bus_Data = MCS_Bus_Read();

    // Step2: 逐位解析故障标志
    MCSFault.OC_U = (MCSFault.MCS_To_APP_Bus_Data >> OC_U_BIT) & 0x1U;
    MCSFault.OC_V = (MCSFault.MCS_To_APP_Bus_Data >> OC_V_BIT) & 0x1U;
    MCSFault.OC_W = (MCSFault.MCS_To_APP_Bus_Data >> OC_W_BIT) & 0x1U;
    MCSFault.OV_Vdc = (MCSFault.MCS_To_APP_Bus_Data >> OV_BIT)  & 0x1U;

    // Step3: 首次故障锁存（记录第一次发生的故障）
    MCSFault.OC_U_State |= MCSFault.OC_U;  // 只置不清
    MCSFault.OC_V_State |= MCSFault.OC_V;
    MCSFault.OC_W_State |= MCSFault.OC_W;

    // Step4: 构建APP→MCS响应
    if (MCSFault.OC_U_State || MCSFault.OC_V_State || MCSFault.OC_W_State) {
        // 触发主动短路（Active Short Circuit）
        // ASC：将三相下管同时导通，电机电流快速泄放
        MCSFault.APP_To_MCS_Bus_Data |= ASC_ENABLE_BIT;
    }

    // Step5: 写回总线（通知MCS硬件执行响应）
    MCS_Bus_Write(MCSFault.APP_To_MCS_Bus_Data);
}
```

### 18.4 主动短路（ASC）机制

```
过流故障检测
     ↓
ASC_Active_Enter_Enable = 1
     ↓
MCS 硬件执行：三相下管同时导通（上管全关）
     ↓
电机成为短路负载，反电动势驱动电流快速衰减
     ↓
电流归零后进入完全关断状态（Free-wheeling）
```
